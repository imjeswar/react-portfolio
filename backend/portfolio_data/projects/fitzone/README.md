# FITZONE – Gym Management Platform

## Overview
FITZONE is a premium, responsive gym management system designed to digitize fitness businesses. The project was inspired by a real-world problem: small gym owners in India managing attendance, fees, and client records on WhatsApp groups or paper books, leading to manual errors and lost membership payments.

## Core Features
- **Client & Staff Portal**: Distinct dashboards for gym managers and registered members.
- **Billing & Subscriptions**: Tracks active memberships, payment status, partial payments, and upcoming renewals.
- **Live Attendance Logs**: Daily check-ins and streaks for gym members.
- **Business Insights**: Analytics dashboard displaying monthly revenue, new sign-ups, and daily gym usage metrics.
- **Mobile First**: Built with responsive layouts so gym staff can manage tasks on their mobile phones.
