# E-commerce Platform with AI Recommendations

## Overview
This project was built to practice developing full-stack web applications with high-fidelity database designs, user sessions/authentication, and customized recommendation engines.

## Core Features
- **Product Catalog**: Allows product filtering, search, and category indexing.
- **Cart & Checkout**: Maintains transaction integrity and basket details.
- **User Authentication**: Secure signup/signin using JSON Web Tokens (JWT).
- **AI Recommendation Engine**: Recommends items based on user purchase histories, search tags, and trending categories.
- **Admin Dashboard**: Interfaces for store managers to add and modify listings.
